## Flixster+ Part 2 Repository Overview - Fall 2024

### Purpose
The Flixster+ Part 2 app extends the previous version by integrating new API endpoints and adding multi-screen functionality. The app allows users to explore and browse various types of movie-related data in creative ways.

### Features
- **API Integration**: Make a request to a chosen endpoint on The Movie Database API (other than `now_playing`).
- **Data Display**: Use a `RecyclerView` to display the fetched data in custom layouts.
- **Image Loading**: Load and display at least one image per entry using Glide.
- **Detail Page**: 
  - Implement a detail page accessible via Intents.
  - Show at least three new pieces of data on the detail page not displayed in the main view.
- **Multi-Screen Functionality**: Use Intents to pass data between different activities or fragments.
